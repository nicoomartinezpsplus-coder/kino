## Готовая версия: ресторан — 46 секунд

Ресторан и драка на кухне, русская озвучка и динамические субтитры по репликам фильма. В конце — пять разных планов главного героя с переходами под акценты музыки: город, вечерний крупный план, автомобиль, маска и выход из ресторана.

Сохранены оригинальные цвета фильма: цветовой фильтр и световые блики убраны. Кадр плавно движется за персонажами, удерживая лица ближе к центру; на спокойных крупных планах добавлено лёгкое приближение. При смене исходного плана кадрирование переключается сразу.

Музыка получена из предоставленного видео-примера с отделением его диалогов. Субтитры соответствуют русской озвучке фильма. В вертикальной версии сверху и снизу используется размытый фон с теми же исходными цветами.
